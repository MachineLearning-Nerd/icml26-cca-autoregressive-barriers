# Branch audit

The original repository exposed one public branch: `main`. The final
repository also exposes only `main`, which is the canonical branch for the
paper audit.

| Branch | Role | Final state |
| --- | --- | --- |
| `main` | README, source record, exact producers, tests, evidence, and publication gate | Canonical public branch |

There are no `orx`, experiment, author-code, or stale publication-queue
branches to interpret. Branch names therefore do not conceal separate
reproduction variants; all claims in the README refer to the files on `main`.
